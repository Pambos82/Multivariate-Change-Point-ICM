# Generated experiment outputs

The runners create separate timestamped subfolders here for benchmarks, full figure sweeps and Air Quality. Short smoke-check logs and reports are retained in separate folders. They preserve earlier runs. Resume only the same sensitivity run with its original settings and `OutputRoot`.

Runtime outputs are ignored by Git. The publication package contains the code and four approved inputs needed to generate them. Keep the [root data attribution](../DATA_ATTRIBUTION.md) with public tables and figures. Downloaded or prepared Air Quality input must stay outside the publication files.
