# Data attribution for research outputs

Keep this attribution with publicly shared tables and figures. The license of a source database remains distinct from the MIT software license.

Credit tables, curves and other produced works contain information from [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud), by Machine Learning Group - ULB, collected through a research collaboration with Worldline, available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Individual contents are covered by [Database Contents License 1.0](https://opendatacommons.org/licenses/dbcl/1-0/). The complete machine-readable derivative is supplied in datasets/creditcard_X.npz; source attribution, modifications and license notices are in [the dataset documentation](datasets/SOURCES_AND_LICENSES.md).

Protein, Particle and Sensorless use the UCI datasets credited in [the dataset documentation](datasets/SOURCES_AND_LICENSES.md), under CC BY 4.0. Keep source and modification attribution with shared data, derived validation fixtures, and adaptations.

Air Quality input is not included. Its original source has conflicting licensing statements, documented in [the preparation instructions](datasets/PREPROCESSING.md). The MIT code license does not grant rights to those source data.
